# 既存kintoneアプリ関係図（As-Is）

## 0. 本書の位置づけ

既存kintone環境の現状（As-Is）を記録する。設計・改善案は含めない。

### 出典

| 資料 | 内容 |
|---|---|
| `local-data/受注管理（選果場出荷物）.zip` | kintoneアプリテンプレート（template.json version "45"、2026-09-23エクスポート）。受注管理アプリと、ルックアップ先3アプリの計4アプリ定義を含む |
| `local-data/受注管理（選果場出荷物）_20260923T101856+0900.csv` | 受注管理レコード29件（2026/09/23出荷予定分、CP932） |
| `local-data/受注管理（選果場出荷物）_20260923T105339+0900.xlsx` | グラフ「本日出荷計画」のダウンロード・加工後ファイル |

`local-data/` はGit管理対象外である。本書には構造情報のみを記載し、取引先の住所・電話番号等の個別データは転記しない。

### 表記

- **【確認済】**：上記資料から直接確認した事実
- **【業務確認済】**：資料外で、業務担当者への確認により確定した事実
- **【推定】**：資料からの推測。未確定
- **【未取得】**：資料がなく不明

### テンプレートに含まれないもの

テンプレートはアプリ定義のみを含む。以下は含まれない。

- 実環境のアプリID（数値）
- ドメイン
- マスタのレコードデータ
- 運用中のアクセス権設定

テンプレート上のACLは4アプリとも空だった。ただし、テンプレートは権限を引き継がない仕様の可能性があり、実環境の権限は【未取得】。

## 2. ルックアップ関係【確認済】

```
受注管理（選果場出荷物）
 ├─ 商品名 ──lookup──▶ 青果物商品マスタ（出荷・在庫用）.商品名
 └─ 出荷先 ──lookup──▶ 青果物出荷先マスタ.出荷先名
                          └─ 得意先名 ──lookup──▶ 顧客情報.得意先名

生産者マスタ ── 既存アプリとの関連は【未取得】
（今回のテンプレートには、生産者マスタを参照するルックアップ・関連レコード一覧は存在しない）
```

### ルックアップ一覧

| 参照元アプリ | 参照元フィールド（コード） | 参照先アプリ | キー（参照先フィールド） | コピーされる項目（参照先 → 参照元） |
|---|---|---|---|---|
| 受注管理 | 商品名（`ルックアップ_0`） | 青果物商品マスタ | 商品名（`文字列__1行_`） | Lot番号 → 商品Lot<br>品名１（佐川） → 品名１（佐川ヤマト共用）<br>使用資材（ラベル袋） → 使用資材<br>資材使用量 → 資材使用量（c/s） |
| 受注管理 | 出荷先（`ルックアップ`） | 青果物出荷先マスタ | 出荷先名（`出荷先名`） | 得意先名 → 得意先<br>住所録コード・依頼主コード（佐川用）<br>お届け先名・住所・郵便番号・会社部門１・電話番号<br>ご依頼主名・住所・郵便番号・電話番号 |
| 青果物出荷先マスタ | 得意先名（`ルックアップ_0`） | 顧客情報 | 得意先名（`文字列__1行_`） | なし（キーのみ） |

- **ルックアップのキーはすべて名称文字列**である。商品名・出荷先名・得意先名はいずれも参照先で「値の重複を禁止」になっている。
- ルックアップはコピー型である。マスタ側を変更しても、既存の受注レコードは自動では更新されない（kintone標準仕様）。
- 受注管理には「関連レコード一覧」フィールドはない。

## 3. 何をSource of Truthとしているか（As-Is）

| 情報 | 現在の保持場所 | 備考 |
|---|---|---|
| 商品情報（商品名・規格・送り状品名・使用資材） | 青果物商品マスタ | 受注へは登録時点の値がコピーされる |
| **商品Lot** | **青果物商品マスタ内のフィールド「Lot番号」**（`数値`、数値型） | **独立した「商品Lotマスタ」アプリは存在しない**。受注管理の「商品Lot」はルックアップでコピーされた値 |
| 出荷先情報・送り状用住所・コード | 青果物出荷先マスタ | 受注へコピーされる |
| 得意先情報 | 顧客情報 | 出荷先マスタ経由で、受注の「得意先」にコピーされる |
| 生産者情報 | 生産者マスタ | 【未取得】 |
| 受注・出荷予定数量 | 受注管理 | |
| 出荷状態・出荷lot | 受注管理（「出荷」「出荷lot」フィールド） | 詳細は ORDER_APP_AS_IS.md |
| 送り状データ | 受注管理からJSでファイル出力 | 送り状番号を保持するフィールドは受注管理に存在しない |
| 仕切り実績・在庫 | kintone上に該当アプリなし（今回資料の範囲） | 現状は紙運用（PROJECT_OVERVIEW.md） |
