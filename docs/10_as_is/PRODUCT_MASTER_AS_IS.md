## 4. 商品名の番号接頭辞【確認済・意味は未確定】

- アプリ説明では接頭辞は分類番号1〜6とされている。

- これら2商品は、接頭辞と商品Lotの値が同じ（15、17）だった。

## 5. 商品Lot

### 5.1 確認済の事実

- **商品Lotは独立したマスタ（アプリ）ではなく、本アプリのフィールド「Lot番号」である。**
  - DECISION_LOG.md の旧記載「既存マスタ：商品Lot」は、独立マスタを意味しない。
- 受注管理の「商品Lot」は、ルックアップ時にコピーされた値である。
- 型は数値である。出荷lot（6桁）の先頭2桁として使われる（BASIC_ARCHITECTURE.md §11）。
- **商品Lotは必ずしも商品名（SKU）ごとに一意ではない。** 受注実データでの確認例：

| 商品名（受注実データ） | 商品Lot |
|---|---|
| 1.筑陽なすＡ長 | 1 |
| 1.筑陽なすA長（35本×2袋入） | 1 |
| 1.筑陽なすA長（60本）ラベル20枚 | 64 |
| 1.筑陽なす3本ｐ | 8 |
| 17.筑陽なすＢ78本入 | 17 |
| 15.刻み（袋） | 15 |
| 3.とろとろ炒めなすＢＣ | 29 |
| 3.とろとろ炒めなす（40ｐ）茶 | 26 |
| 3.とろとろ炒めなす18ｐ（袋） | 22 |
| 3.山斗30ｐ | 34 |
| 3.とろうま甘茄子80本 | （空欄） |

### 5.2 意味の確認が必要な既存項目

- 同じ商品Lotが異なる商品名に付いている理由・意味は**未確定**である。
  - 例：「A長」と「A長（35本×2袋入）」がどちらも1。
- 現段階では「在庫グループ」「物理商品コード」等と**推測で定義しない**。
- 商品Lotが空欄の商品がある理由（例：3.とろうま甘茄子80本）も未確認である。
- マスタ全件の値の分布は【未取得】。

- アプリ名に「在庫用」とあるが、在庫数量や在庫管理用の項目は現状存在しない。
- 商品ごとの在庫管理単位・ケース換算値は、今後の詳細設計で決める。本書では値を推測しない。
