## 4. 商品名の番号接頭辞【確認済】

アプリ説明欄では、接頭辞は半角の分類番号1〜6とされている。CSV（181件）の実態は次のとおり。

| 区分 | 件数 | 例 |
|---|---|---|
| 半角「1.」〜「6.」 | 149 | |
| 「7.」以上の数字 | 25 | 7, 14, 15, 16, 17, 20, 36, 44, 46〜49, 52, 53, 56〜63 |
| 全角数字「４.」 | 4 | |
| 接頭辞なし | 3 | いちご360ｇＬ24玉トレー 等のいちご商品 |

- **説明欄のルールは実データでは守られておらず、商品名先頭番号は信頼できる分類キーではない。**
- 「7.」以上の接頭辞には、商品Lotと同じ数字のものがある（例：15.刻み（袋）＝Lot 15、17.筑陽なすＢ78本入＝Lot 17、36.〜＝Lot 36）。
- 一方で、接頭辞とLotが一致しないものもある（例：1.雅香岡田＝Lot 5）。
- 接頭辞の現在の採番ルールは【未取得】。

## 5. 商品Lot

### 5.1 確認済の事実

- **商品Lotは独立したマスタ（アプリ）ではなく、本アプリのフィールド「Lot番号」である。**
- 受注管理（選果場出荷物）の「商品Lot」は、ルックアップ時にコピーされた値である。受注管理（産直出荷物）には商品Lotフィールドがない。
- 型は数値である。出荷lot（6桁）の先頭2桁として使われる。
- CSV 181件の内訳：Lot番号あり 66件（55種類）、空欄 115件。
- **商品Lotは商品名（SKU）ごとに一意ではない。** 2件以上の商品に付いているLotが9種類ある。

| 4 | 4.火の国なす2本ｐ（GN）、4.火の国なす2本ｐ（Oisix） |
| 5 | 5.筑陽なす1本漬、1.雅香岡田 |
