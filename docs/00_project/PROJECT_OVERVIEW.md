# 選果場DX

## 目的

選果場に大型モニター1台とタブレット3台を導入し、
現在紙を中心に行っている出荷情報掲示、仕切り、
在庫管理、出荷時入力をkintoneへ移行する。

## 基本方針

- kintoneを中心に構築する
- 既存受注管理アプリは原則継続
- 既存商品マスタを継続利用
- 既存出荷先マスタを継続利用
- 仕切り管理を新規構築
- 出荷処理を新規構築
- 在庫管理を新規構築
- 大型モニターは受注管理等のデータを表示するUI
- タブレットは現場入力用UI

## 開発方針

- 業務要件・全体設計: ChatGPT
- 技術詳細設計: Claude Code Plan Mode
- 実装: Claude Code
- 実機確認: 現場
